# 实验四：前端课程静态网页开发
## 作业内容
制作课程展示静态网页，包含固定导航栏、Banner横幅下拉菜单、课程推荐、精品课程卡片、学科课程模块与页脚，综合练习Flex、Grid布局、CSS定位、过渡动画与响应式媒体查询。

## 使用主要知识点
1. 布局：Flex弹性布局完成一维横向排版；Grid网格布局实现课程卡片二维网格排列
2. CSS定位：position: fixed实现顶部固定导航；position: relative + position: absolute，子绝父相原理实现Banner下拉菜单
3. 伪类：:hover鼠标悬浮样式切换，卡片上浮与阴影交互效果
4. 过渡动画：transition配合transform，实现卡片平滑上浮动效
5. 响应式：@media媒体查询，适配移动端小屏幕布局
6. HTML结构：ul、li无序列表搭建导航和课程列表结构

## 遇到的困难与解决方法
1. 困难：fixed固定导航脱离文档流，页面顶部内容被导航遮挡。解决：给body设置padding-top，预留导航栏高度空间。
2. 困难：浏览器缩小到移动端尺寸，课程卡片网格布局错乱。解决：添加媒体查询，修改Grid列数，小屏幕下调整弹性布局。
3. 困难：卡片hover上浮效果生硬，没有动画感。解决：使用transition设置过渡时长，搭配transform: translateY实现平滑上浮。
